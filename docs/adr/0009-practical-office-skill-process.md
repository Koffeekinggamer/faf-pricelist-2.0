# Adopt Practical-Office skill process; keep mattpocock skill packages

[Practical-Office/Cursor-AI-dev](https://github.com/Practical-Office/Cursor-AI-dev) is a **course + living process** for Cursor + mattpocock/skills. It does not publish a better skills pack — its README names [mattpocock/skills](https://github.com/mattpocock/skills) as the skills source of truth (already installed under `.agents/skills/`).

What we adopt: their **taxonomy** (user-invoked vs model-invoked), **preferred chain**, and **non-negotiables** (spec gates, ticket kill test, Red→Green-only implement, dual-axis review). Documented in `docs/agents/skill-process.md` and summarized in `AGENTS.md`. Caveman remains as a typed style skill.

What we do **not** adopt: course HTML modules, Practical-Office-only `.cursor/rules` doctrine, or replacing mattpocock skill files with course copies.

**Status:** accepted
